# 🧠 SpikeEmbed

**Unsupervised Neuromorphic Sentence Embeddings using Spiking Neural Networks (SNN)**

SpikeEmbed is a lightweight, low-power sentence embedding model built on top of Oxide-JS. It introduces **Sequence-as-Time Spiking Dense BPTT** and **Spike-Count Accumulation** to natively model language structures without relying on floating-point matrix multiplications during inference.

## Features & Novelties
1. **Dynamic Spiking Dense BPTT**: Processes sequence tokens as temporal steps naturally using Leaky Integrate-and-Fire (LIF) dynamics.
2. **L2-Normalized Spike Accumulation**: Resolves the membrane saturation limit (`1.0`) on long sentences by accumulating spike counts over time and projecting them to a hypersphere.
3. **Positive Orthant Correction**: Introduces **Mean-Centered Cosine Similarity** to correctly rank Semantic Textual Similarity (STS) vectors generated by strictly positive SNN spikes.
4. **Unsupervised Add-Only Hebbian Learning**: Trains embeddings natively without backpropagation, accelerated via Rust FFI.
